# NOVA Launcher

A free, non-commercial launcher for **Minecraft: Java Edition** by **Voltiel**.
Бесплатный некоммерческий лаунчер Minecraft: Java Edition от Voltiel.

🌐 Website: https://voltiel.github.io/NovaLauncher/

## Features
- Microsoft sign-in (licensed accounts only), multiple accounts
- Instances with their own folder, version, memory and JVM arguments
- Mod loaders: Vanilla, Fabric, Quilt, Forge, NeoForge
- Mods and modpacks from Modrinth (`.mrpack` import/export)
- Automatic Java installation, live game console, play time tracking
- Russian and English UI

## Status
In development.

## Privacy
Passwords are entered only on Microsoft's own sign-in page. Refresh tokens are stored locally in Windows Credential Manager. No account data is sent to any server other than Microsoft, Xbox Live and Minecraft Services.
